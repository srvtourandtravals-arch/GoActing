# Acting Driver Booking Platform

## Project Overview
The Acting Driver Booking Platform is designed to connect passengers with drivers seamlessly. It aims to provide a user-friendly experience for booking rides and managing travel logistics.

## Features
- User registration and login
- Driver registration and verification
- Ride booking and management
- Payment processing
- User reviews and ratings for drivers

## Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Deployment:** AWS

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/srvtourandtravals-arch/GoActing.git
   ```
2. Navigate to the project directory:
   ```bash
   cd GoActing
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

## Folder Structure
```bash
GoActing/
├── client/        # Frontend code
├── server/        # Backend code
├── database/      # Database configuration
├── .env           # Environment variables
└── README.md      # Project documentation
```
